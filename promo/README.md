# Ролик dev.txt

`index.html` — ролик как анимация: весь фильм — функция `drawAt(t)`, которая рисует секунду `t` на холсте 1080×1920.
Поэтому он одинаково играет на странице и отрисовывается в видеофайл покадрово, без пропусков.

Чтобы получить видео: раздать эту папку локальным сервером, который принимает `POST /имя` и кладёт тело в `out/`,
открыть страницу в браузере на Chromium, подключить `tools/render.js` и вызвать `renderPromo({ fps: 30 })`.
Получатся `dev-txt-promo.mp4` (H.264) и `dev-txt-promo.webm` (VP9). Оба контейнера пишутся в `render.js` без библиотек.

Сами видеофайлы в репозиторий не кладутся. Звука в ролике нет.
